# Website rules, draft (from Wispr, Superhuman and Macro; Linear to confirm)

**Status:** DRAFT, 2026-10-08. Not approved. Written so Home v3 (`prototypes/2026-10-08-home-v3/`) has rules to follow
and so the founder can react to rules, not only to pictures. Linear's teardown is still running; it confirms or
changes these. Sources: `2026-10-08-four-favourites-teardown.md` (part 2 for Wispr, Superhuman, Macro).

1. **Rhythm.** Dark first screen, light middle, dark close. Never black everywhere (R-018). The dark is a neutral
   or warm near-black, never blue (R-031). *Wispr (light/dark blocks), Macro (dark), A-009.*
2. **One section template.** Mono label in the owner's words ("When a customer writes"), a centred serif title with
   the human phrase in italic (A-104), one grey line, then one scene. Same every time. *Macro, Superhuman, Linear.*
3. **One customer, one story.** The scenes follow one example customer through the chapters (writes → a decision →
   goes quiet → answers), labelled "An example, not a real customer." *Wispr ("the same message all the way
   through"), Macro (short chats with names), A-063.*
4. **Colour has jobs.** Neutrals for the page; the wash only on FollowUp's reply; the orange dot only for "needs
   you"; green only for "done / stopped". The button is cream on dark, ink on light. *Macro (colour only around the
   product), Wispr (one button colour).*
5. **Depth without shine.** Depth comes from value contrast, one thing in front of another, plain dark shadows, and
   far things smaller and fainter. No glows, halos or glossy edges (R-036). *Founder, 2026-10-08.*
6. **Type.** Instrument Serif headlines (hero 96, sections 64, scenes 25–28), Public Sans body 16–19 at ~450, IBM
   Plex Mono labels 11–12 px caps with 0.12em tracking.
7. **Calm motion.** Arrivals are opacity plus a short rise, 0.6 s on `cubic-bezier(0.22, 1, 0.36, 1)`; hovers 0.18 s;
   nothing bounces, nothing shines. *Superhuman, Macro.*
8. **The visitor holds the controls.** Every scene that plays has Pause and Replay and a status line that says what
   is happening; reduced motion shows the end state. Nothing traps the mouse wheel. *Macro, WCAG 2.2.2, A-063.*
9. **You always know where you are.** After the first screen a slim bar stays on top with the chapters and the one
   button. *Superhuman's sticky tabs.*
10. **One button, start to finish.** "Connect Gmail, start free" everywhere; the closing one is the same button,
    bigger. *Macro.*
11. **Honest proof only.** No invented testimonials, logos or badges; a small footer with Privacy (Google's OAuth
    verification needs it on the home page). *Our own rule; what we don't copy from Macro.*
