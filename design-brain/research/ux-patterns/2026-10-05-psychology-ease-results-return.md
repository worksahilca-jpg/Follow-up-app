# Psychology for FollowUp: easy to use, shows results, keeps them coming back (2026-10-05)

**Why:** founder: *"read all the psychological books so that… it is easy for them to use and they should see the
results… and they should keep using this… also the colours… it should be strategic."* **Evidence, honestly:** grade B.
No book was read in full from here; this is from the authors' own summaries, the original studies' abstracts and
secondary write-ups (sources at the end). Numbers quoted are the studies' own.

**The rule above every idea here:** psychology is used to make FollowUp easier and to show results that are true. Never
fake urgency, invented counts, streaks or badges (A-038, A-046), guilt copy, or an exit harder than the entry. Cialdini's
own line: pointing to something real is fair; inventing it is manipulation. Brand principle 1 (trust) outranks every
conversion lift below.

| Idea | Source | Rule for FollowUp |
|---|---|---|
| System 1 / cognitive ease; defaults; loss aversion | Kahneman, *Thinking, Fast and Slow* | Every screen answerable on autopilot. Safe defaults do the thinking (A-070). Loss framing never used to scare ("leads slipping away"). |
| B = Motivation × Ability × Prompt | Fogg, *Tiny Habits* | Design ability and the prompt, not motivation: the prompt is a real customer writing, the action one press. |
| Trigger → action → variable reward → investment | Eyal, *Hooked* (and its critics) | The reward is real (they replied, they booked), never a slot machine. Investment = FollowUp learning the owner's voice (learn-from-edits: not yet approved). |
| Labour illusion / operational transparency | Buell & Norton, *Management Science* 2011 | Show the work FollowUp did, in one honest line. People value a service more when they see the effort. |
| Peak-end | Kahneman; Yablonski | Put the real outcome on the peak (Sent) and the end (done for today). |
| Endowed progress | Nunes & Drèze 2006 (34% vs 19% completion) | Setup counts what is already done. |
| Colour-in-context | Elliot & Maier | Calm and cool for the work screens (trust in serious tasks); warmth for welcome moments (the wash); red never means "you did badly". Guides check-up #19/#20; any token change is `[TO DECIDE]`. |
