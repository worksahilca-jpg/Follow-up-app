# Design and UX

For any design or UI work — a new screen, a meaningful change to an existing one, a new
component, a token change, or copy that carries UX weight — read `../CLAUDE.md` and follow
the FollowUp Design Brain in `../design-brain/`.

Start with `../design-brain/README.md`. Always check `../design-brain/decisions/rejected.md`
before proposing a design.
