# The judging test: 30 messages for a realtor to mark

**Why.** FollowUp's call (Ready, Warm, Later, Has an agent) needs right answers that come from a real realtor, not
from us. A realtor marks these 30 made-up but realistic messages in [realtor-judging-sheet.xlsx](realtor-judging-sheet.xlsx) (about 10 minutes).
Their answers become the accuracy test for section 1 (whom) and section 2 (judge) of [real-estate.md](real-estate.md).

**What the realtor picks for each message:**
- Real customer? Yes / No
- Where do they stand? Ready / Warm / Later / Has an agent / Can't tell yet
- What would you do next? Call them today / Reply and offer a showing or visit / Reply with a question / Follow up later / Stop following up / Don't reply
- Anything they'd say or do (optional, free text)

The sheet gives the realtor only plain meanings (Ready = "you'd call them today"), never FollowUp's own rules, so the
answers test whether FollowUp's rules match a realtor's judgement.

**When the answers come back:** each message becomes a test case with the realtor's answer as the right one. It is
run against the real model, like the other four accuracy tests. Where FollowUp and the realtor disagree, the founder
decides which is right, and the playbook and the code follow. More than one realtor's answers are better: where
realtors disagree with each other, the message is marked "judgement call" and not counted against FollowUp.
