# Research

Dated findings from FollowUp's research agents — see `.claude/agents/README.md` for the full team roster and how work flows from here into the product.

- `market/` — competitor and category research (`market-research-agent`)
- `customers/` — ICP, pain points, objections (`customer-research-agent`)
- `integrations/` — production-readiness per real integration (`integrations-research-agent`)

Each subfolder is a set of dated, single-topic write-ups (one file per competitor, per integration, per research pass) — extend with a new file rather than rewriting an old one, so the history of what was known when stays intact.
