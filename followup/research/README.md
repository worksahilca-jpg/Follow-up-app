# Research

Dated findings from FollowUp's team — see `.claude/agents/README.md` for the full org chart and how work flows from here into the product.

- `market/` — competitor and category research (`product-ux-agent`)
- `customers/` — ICP, pain points, objections (`product-ux-agent`)
- `integrations/` — production-readiness/compliance per real integration (`qa-security-agent`)
- `audit/` — concrete code-level bug findings from code-audit and pentest passes (`qa-security-agent`)

Each subfolder is a set of dated, single-topic write-ups (one file per competitor, per integration, per research pass) — extend with a new file rather than rewriting an old one, so the history of what was known when stays intact.
